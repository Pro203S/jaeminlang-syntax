# jaeminlang-syntax

[재민랭](https://github.com/Pro203S/jaeminlang)의 하이라이팅, 포맷팅을 지원하는 VSCode 확장 프로그램입니다.  


## 사용법

- `.jml` 파일을 열면 재민랭 언어 모드가 자동 적용됩니다.
- 명령어, 주석(`어이쿠`), 문자열과 이스케이프, 숫자, `여친`, 연산자, 배열·딕셔너리 기호를 하이라이팅합니다.
- **문서 서식 지정** 명령으로 포맷팅합니다. 포맷터 선택 시 **jaeminlang-syntax**를 선택하세요.
- **줄 주석 토글** 명령으로 `어이쿠` 주석을 추가하거나 제거합니다.

저장 시 자동 포맷팅은 설정에 다음을 추가합니다.

```json
"[jaeminlang]": {
  "editor.formatOnSave": true
}
```

## 포맷팅 규칙

명령어 앞뒤 공백, 주석 앞 들여쓰기, 공백만 있는 줄을 정리합니다.
재민랭 파서는 인수 공백을 그대로 사용하므로 쉼표 뒤 공백을 추가하거나 인수 공백을 제거하지 않습니다.
공백이 포함된 변수명, 문자열, 이스케이프와 주석 내용은 보존합니다.
`러스트`의 줄 번호가 바뀌지 않도록 빈 줄과 줄바꿈 형식, 마지막 줄바꿈 유무도 유지합니다.
함수 들여쓰기는 명령어 인식을 방해하므로 추가하지 않습니다.

## 개발

`npm install` 후 `npm run compile`로 빌드하고, VS Code에서 F5로 확장 개발 호스트를 실행합니다.
배포용 번들은 `npm run package`로 생성합니다.

## 이름 하이라이팅

변수명은 `variable.other.readwrite`, 함수명은 `entity.name.function`, 매개변수는 `variable.parameter`로 구분합니다. 실제 색상은 선택한 테마에 따릅니다.
같은 파일의 함수 선언과 본문을 분석해 매개변수 선언·참조 및 `안산`, `그램`, `음...`의 함수 호출을 추가로 표시합니다. 이 분석에는 VS Code의 의미 체계 강조 표시가 활성화되어 있어야 합니다.
가져온 파일의 함수 정의는 분석하지 않으며, 네트워크 모드의 `엘릭서`는 함수 선언 분석에서 제외합니다.
